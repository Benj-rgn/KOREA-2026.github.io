# Korea 2026 — V5

Travel companion website for the Korea 2026 trip.

## Architecture
- `index.html` — page structure
- `css/styles.css` — responsive design system
- `js/data.js` — trip content
- `js/app.js` — interactions, filters and voting

## Validated V5 design palette
- Main: `#248591`
- Accent / CTA: `#FF7420`
- Secondary: `#8C4218`
- Background: `#F7F4EB`
- Soft background: `#E8D8CA`
- Borders: `#C8AD98`
- Cards: `#FFFFFF`

Mobile navigation is a fixed bottom navigation, as validated in the design direction.
